# 分裂棋 · Split Chess

一颗落子，一场连锁。适合手机触控的独立 H5 休闲棋类游戏。

## 游玩

在线地址：https://reoxy258.github.io/split-chess/

人机对战：你执蓝方先手，电脑执橙方。同机双人：双方共用屏幕轮流落子。
首次进入可体验四步互动教程；随时在「玩法说明」中重看。棋局自动保存在当前浏览器。
人机悔棋撤回一整轮；电脑思考时悔棋可撤回刚才的人类落子。双人模式每次撤回一手。

## 确定规则

- 棋盘可选 5×5～10×10，默认推荐 7×7，每回合只能在空格或己方格加 **1 点**。
- 格子达到 4 点，消耗 4 点，向上下左右各送 1 点。若同时收到多点，多余点数保留。
- 扩散进入敌格，整格归进攻方，原点数保留再相加；达到 4 点继续分裂。
- 所有扩散继承当前回合方颜色。按同步波次结算，完整连锁结束前不换手、不判胜。
- 边角统一满 4 才分裂，超出棋盘的点消失。边界耗散让每次连锁最终结束。
- 双方各实际落子至少一次后，完整连锁结束时清空对方棋子者获胜。
- 稳定棋盘每格只显示 1～3 点；4 点以上只会在连锁过程短暂出现。
- 无道具或随机规则。棋局没有强制回合上限，受整局时限约束。

## 限时对局（1.1.0）

| 棋盘 | 整局时长 | 每手时限 |
|---|---|---|
| 5×5 | 3分钟 | 15秒 |
| 6×6 | 4分钟 | 18秒 |
| 7×7（推荐） | 5分钟 | 20秒 |
| 8×8 | 6分钟 | 22秒 |
| 9×9 | 8分钟 | 25秒 |
| 10×10 | 10分钟 | 30秒 |

首次落子或点击「开始计时」启动。整局到时比较双方所有棋子的点数总和，点数较多者获胜；同分加时60秒，仍同分继续加时。提前清空对方仍可获胜。
单步超时跳过本回合；跳过不算实际落子，不触发清空判胜。整局和单步同时到时，优先判整局结果。
连锁结算不扣时间；AI思考计入其落子时间。教程、说明弹窗及切到后台会暂停，返回或刷新后点击「继续对局」。
悔棋只撤回棋盘，不返还整局或当前单步已消耗时间。到时结算后的棋局不可悔棋。
切换尺寸会重开，已有进度时先确认；旧6×6与10×10存档及同尺寸历史保留原局，不裁切或扩展。

## 本地开发

不需要安装第三方依赖，使用 Node.js 20 或更高版本。

    npm start
    npm test
    npm run build:offline

预览为 http://127.0.0.1:4173/ 。可用环境变量 PORT 指定其他端口。
离线构建在项目父目录生成「分裂棋.html」，双击即可游玩；离线电脑通过同一规则引擎在主线程思考。

## 实现

- engine.js：不可变状态、确定性规则、同步连锁、两层搜索电脑策略。
- app.js：交互、动画、教程、存档和取消过期异步任务。
- ai-worker.js：将在线电脑搜索放入 Worker，保持界面响应。
- style.css / index.html：响应式棋子界面（chess-crash 同款数字圆子：天蓝/琥珀底 + 白色数字，三点将裂格赤红呼吸脉冲）；键盘方向键和 Enter/空格亦可操作。
- tests/rules-review.test.js：独立串行参照、4000 手随机对照、密集棋盘和 AI 验证。
- tests/ui-lifecycle.test.js：教程、动画锁、取消 AI、悔棋、恢复等生命周期回归。
